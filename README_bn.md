### মেমরি/ডিস্ক সমস্যার সমাধান: **দুই-পাস স্ট্রিমিং (ডিস্ক-ছাড়া)**
২GB ফাইল ৫১২MB RAM-এ ঢোকে না, আর Render ফ্রি-র ডিস্কের সাইজও ডকুমেন্টেড নয়। তাই `upload` মোডে:

1. `stream_media` দিয়ে টেলিগ্রাম থেকে **৪MB করে ব্লক** পড়া হয় (অফসেট দিয়ে যেকোনো ব্লক আলাদাভাবে আবার আনা যায়)।
2. **পাস ১:** প্রতি ব্লকের MD5 বের করে ফেলে দেওয়া হয় (TeraBox `precreate`-এ আগে MD5 লিস্ট চায়)।
3. **পাস ২:** আবার ব্লক আনা হয় এবং সরাসরি TeraBox-এ আপলোড হয়।

ফলাফল: **RAM ≈ ১০–২০MB, ডিস্ক = ০।** দাম: টেলিগ্রাম থেকে ফাইল দুইবার নামে (সময় দ্বিগুণ — রাতারাতি চালালে সমস্যা নেই)।

### কমপ্রেশন নিয়ে সৎ কথা
Render ফ্রি-র **0.1 CPU** মানে একটা কোরের ~১০%। FFmpeg চলবে, কিন্তু **অনেক ধীর** (মোটামুটি ১ ঘণ্টার ভিডিও কয়েক ঘণ্টা — ভিডিও/রেজোলিউশনভেদে বদলায়)। তাছাড়া কমপ্রেস মোডে ইনপুট+আউটপুট ডিস্কে লাগে, তাই `/disk` কমান্ডে ফ্রি স্পেস দেখে নিন; জায়গা কম হলে বট নিজেই কাজ রিজেক্ট করে `upload` মোড সাজেস্ট করে।
- `-preset ultrafast` দ্রুত কিন্তু ফাইল **বড়** হয় (কমপ্রেশন কমে যায়)। তাই ডিফল্ট `veryfast` + `CRF 28` + ৭২০p। আরও ধীর CPU-তে `X264_PRESET=ultrafast` দিন।
- `FF_THREADS=1` (ডিফল্ট) + `nice` — যাতে ওয়েব সার্ভার/বট রেসপন্সিভ থাকে।
- ভিডিও যদি কমপ্রেসে ছোট না হয়, বট অরিজিনালই রাখে।

> বড় পরিমাণ রি-এনকোডিং দরকার হলে ফ্রি Render-এ এটা মূলত "ধীর কিন্তু সম্ভব"। দ্রুত করতে চাইলে কার্ড ছাড়া আর ভালো ফ্রি কম্পিউট নেই; GitHub Actions/Kaggle-এর মতো অপশন আছে কিন্তু তাদের নিজস্ব শর্ত/ভেরিফিকেশন আছে — এই প্রজেক্টে ধরা হয়নি।

`bot.py`, `terabox.py`, `Dockerfile`, `requirements.txt` — চারটাই একই ফোল্ডারে (GitHub রিপোর অ্যারে root-এ)।

## ৩. Environment Variables

| নাম | কী | কোথায় পাবেন |
|---|---|---|
| `API_ID`, `API_HASH` | টেলিগ্রাম অ্যাপ ক্রেডেনশিয়াল | my.telegram.org → API development tools |
| `BOT_TOKEN` | বট টোকেন | @BotFather |
| `OWNER_IDS` | আপনার টেলিগ্রাম আইডি (একাধিক হলে কমা দিয়ে) | @userinfobot |
| `TERABOX_NDUS` | TeraBox `ndus` কুকি | নিচে দেখুন |
| `DEFAULT_MODE` | `upload` / `compress` / `cupload` (ঐচ্ছিক) | — |
| `X264_PRESET`, `CRF`, `MAX_HEIGHT`, `FF_THREADS` | কমপ্রেশন টিউনিং (ঐচ্ছিক) | — |
| `TERABOX_DIR` | TeraBox-এ ফোল্ডার, ডিফল্ট `/TGBot` | — |

**মোবাইলে `ndus` কুকি নেওয়া:** Firefox for Android ইনস্টল করুন → terabox.com-এ লগইন → Add-ons থেকে **Cookie-Editor** ইনস্টল → টেরাবক্স পেজে Cookie-Editor খুলে `ndus` এর Value কপি করুন।

## ৪. ডেপ্লয় (সবকিছু ফোনের ব্রাউজার থেকে)

1. **GitHub:** github.com → New repository (Private রাখুন) → *Add file → Upload files* → ৪টি ফাইল সিলেক্ট করে → Commit।
2. **Render:** dashboard.render.com → *New → Web Service* → GitHub রিপো কানেক্ট → **Language/Runtime: Docker** → **Instance Type: Free** → Environment Variables বসান → *Deploy*।
3. লগে `Application startup` ও আপনার বটে "🟢 বট চালু" মেসেজ এলে ঠিক আছে।
4. **জাগিয়ে রাখা:** বট নিজে `RENDER_EXTERNAL_URL`-এ প্রতি ১০ মিনিটে পিং করে। এর পাশাপাশি **cron-job.org** বা **UptimeRobot** (ফ্রি, কার্ড লাগে না) দিয়ে আপনার `https://xxxx.onrender.com/` প্রতি ৫ মিনিটে পিং করান — ব্যাকআপ হিসেবে।
5. **গুরুত্বপূর্ণ:** Render ফ্রি-তে **৭৫০ ইনস্ট্যান্স-ঘণ্টা/মাস পুরো ওয়ার্কস্পেসের জন্য শেয়ার্ড**। একটা সার্ভিস ২৪/৭ চললে ~৭৪৪ ঘণ্টা লাগে। আপনার পুরোনো ফ্রি বটগুলো থাকলে **সেগুলো Suspend করুন**, নইলে মাস শেষের আগেই ঘণ্টা ফুরোবে।
6. টেস্ট: বটে `/tbtest` → ✅ এলে একটা ছোট ভিডিও ফরওয়ার্ড করে `upload` মোডে দেখুন → তারপর বড় ফাইল।

## ৫. ব্যবহার
ভিডিও (এক বা একাধিক) ফরওয়ার্ড করুন। `/mode` দিয়ে মোড বাছুন:
- ☁️ **upload** — অরিজিনাল ভিডিও TeraBox-এ (ডিস্ক-ছাড়া)
- 🗜 **compress** — কমপ্রেস করে টেলিগ্রামে ফেরত
- 🗜☁️ **cupload** — কমপ্রেস করে TeraBox-এ

কমান্ড: `/queue` `/cancel` `/clear` `/disk` `/tbtest`

## ৬. ঝুঁকি ও এজ-কেস

1. **TeraBox কোড অপরীক্ষিত/আনঅফিশিয়াল।** আমি এটা এখানে রান করে টেস্ট করতে পারিনি। TeraBox অফিশিয়াল আপলোড API দেয় না; ওয়েব এন্ডপয়েন্ট বদলালে বা ডেটাসেন্টার IP-তে ক্যাপচা/ভেরিফিকেশন চাইলে ব্যর্থ হতে পারে। ব্যর্থ হলে বটে হুবহু এরর JSON আসবে — সেটা দিয়ে `terabox.py` ঠিক করা যাবে। `compress` মোড TeraBox-এর উপর নির্ভর করে না, তাই সেটা ব্যাকআপ।
2. **কুকি মেয়াদ:** `ndus` এক্সপায়ার/লগআউট হলে ❌ মেসেজ আসবে → নতুন কুকি নিয়ে Render-এ env আপডেট করুন (অটো রিডেপ্লয় হয়)। টেরাবক্স অ্যাকাউন্ট অন্য ডিভাইসে লগআউট করলে কুকি অচল হতে পারে।
3. **রিস্টার্টে কিউ হারানো:** Render ফ্রি-র ডিস্ক ephemeral; ডিপ্লয়/রিস্টার্টে `state.json` মুছে যায়। বট স্টার্টে জানায় কয়টা কাজ পুনরুদ্ধার হলো — না হলে ভিডিও আবার ফরওয়ার্ড করুন। (স্থায়ী কিউ চাইলে ফ্রি MongoDB Atlas M0 যোগ করা যায়।)
4. **ফ্লাডওয়েট:** প্রগ্রেস এডিট ১০ সেকেন্ডে একবার; অনেক ভিডিও ফরওয়ার্ডে একটাই সারাংশ মেসেজ।
5. **ফাইল সীমা:** টেলিগ্রাম বট ২GB পর্যন্ত নামাতে/তুলতে পারে। কমপ্রেসের পরও ২GB ছাড়ালে বট জানাবে। TeraBox ফ্রি অ্যাকাউন্টের নিজস্ব ফাইল-সাইজ/স্পিড সীমা থাকতে পারে — আপনার অ্যাকাউন্টে যাচাই করুন।
6. **নিরাপত্তা:** `OWNER_IDS` বাধ্যতামূলক; রিপো Private রাখুন; কুকি/টোকেন কখনও কোডে বা পাবলিক রিপোতে দেবেন না — শুধু Render env-এ।
7. **Render শর্ত:** ফ্রি টিয়ার বদলাতে পারে (স্লিপ-টাইম আগে ৩০ মিনিট ছিল, এখন ১৫)। ভারী বা ২৪/৭ ব্যবহারে Render ফ্রি সীমা কমে আসতে পারে।
8. **কপিরাইট/ToS:** TeraBox-এর আনঅফিশিয়াল অটোমেশন তাদের শর্তে পড়ে কি না নিজে দেখে নিন; অ্যাকাউন্ট রেট-লিমিট বা ব্লক হওয়ার ঝুঁকি আছে।
